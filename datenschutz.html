Datenschutz

Stand: 9. Mai 2026 · gilt für eigenregie.ch und das Software-Produkt „Regie".

In Kurz: Eigenregie sammelt keine personenbezogenen Daten auf der Website. Es gibt kein Tracking, keine Analytics, keine Cookies (ausser die, die der Lemon-Squeezy-Checkout für die Zahlungsabwicklung setzt). Die Software „Regie" speichert ausschliesslich auf deinem eigenen Gerät — keine Daten verlassen deinen Computer.

1. Verantwortlicher

Verantwortlich für die Datenverarbeitung ist Rafael Stoffel. Kontakt: rafaelstoffel.ai@gmail.com. Anschrift auf Anfrage.

2. Welche Daten werden verarbeitet

2.1 Beim Aufruf von eigenregie.ch

Die Website wird über GitHub Pages ausgeliefert (GitHub Inc., 88 Colin P Kelly Jr St, San Francisco, CA 94107, USA). GitHub erfasst beim Aufruf technisch notwendige Daten — IP-Adresse, Datum und Uhrzeit, User-Agent — zur Auslieferung der Inhalte und zur Abwehr von Angriffen. Diese Daten verarbeitet GitHub eigenverantwortlich gemäss GitHub-Datenschutzerklärung.

Eigenregie hat keinen Zugriff auf diese Server-Logs und führt selbst keine Web-Analyse, kein Tracking und keine Reichweitenmessung durch.

2.2 Schriften (Google Fonts)

Diese Website lädt die Schriften „Inter" und „Syne" von Google Fonts (Google Ireland Limited, Gordon House, Barrow Street, Dublin 4, Irland). Beim Aufruf wird deine IP-Adresse an Google übertragen, damit die Schriften ausgeliefert werden können. Es werden keine Cookies gesetzt. Rechtsgrundlage ist das überwiegende Interesse an einer einheitlichen, lesbaren Darstellung (Art. 31 Abs. 2 lit. c DSG).

2.3 Beim Kauf von „Regie"

Der Verkauf läuft über Lemon Squeezy (Lemon Squeezy LLC, Houston, TX, USA). Lemon Squeezy ist Merchant of Record und verarbeitet:

  • E-Mail-Adresse — zur Lieferung des Download-Links und der Rechnung
  • Zahlungsinformationen — Kreditkarte, PayPal o.ä., abgewickelt durch Lemon Squeezy bzw. dessen Zahlungs-Provider
  • Rechnungsadresse — für die korrekte Erhebung der Mehrwertsteuer (CH-MwSt automatisch)
  • IP-Adresse, technische Geräteinformationen — zur Betrugsprävention

Eigenregie erhält von Lemon Squeezy die Käufer-E-Mail-Adresse, die Bestellnummer und den Zahlungsstatus zur Vertragsabwicklung. Details zur Lemon-Squeezy-Datenverarbeitung findest du in der Lemon-Squeezy-Datenschutzerklärung.

2.4 Bei E-Mail-Kontakt

Wenn du Eigenregie per E-Mail kontaktierst, werden deine E-Mail-Adresse und der Inhalt der Nachricht ausschliesslich zur Bearbeitung deiner Anfrage gespeichert. Es erfolgt keine Weitergabe an Dritte. Anfragen werden gelöscht, sobald sie erledigt sind und keine gesetzliche Aufbewahrungspflicht entgegensteht.

3. Cookies

Die Website eigenregie.ch selbst setzt keine Cookies. Wenn du auf einen „Kaufen"-Button klickst und zum Lemon-Squeezy-Checkout weitergeleitet wirst, setzt Lemon Squeezy auf deren eigener Domain die für die Zahlungsabwicklung notwendigen Cookies.

4. Daten in der Software „Regie"

„Regie" ist eine lokal laufende Anwendung. Alle eingegebenen Daten — Projekte, Phasen, Aufgaben, Zeiterfassung, Zeitnotizen — werden ausschliesslich auf deinem Gerät gespeichert: entweder in einem von dir gewählten Ordner (File System Access API) oder im Browser-Speicher (localStorage). Diese Daten werden zu keinem Zeitpunkt an Eigenregie, an einen Server oder an Dritte übermittelt. Es gibt keine Telemetrie, keine Crash-Reports, keine automatischen Update-Checks gegen einen Server.
